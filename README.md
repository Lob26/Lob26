### What I'm building

**FDE, a Fraud Detection Engine** · `seed` · `private for now`<br>
Real-time fraud detection as an event-driven proof of concept. A Go gateway feeds Kafka, partitioned by entity. A Rust feature core is exposed to Python through PyO3, Python makes the decisions, and a Next.js war room lets an analyst step in live. Every stack choice has an ADR, and any piece that doesn't earn its place gets cut.

**[Culturas Gastronómicas Redux](https://github.com/Lob26/culturas-gastronomicas-redux)** · Angular · Spring Boot · pgvector<br>
A 2023 course project I rebuilt from scratch. It includes a self-hosted assistant that answers from the catalogue itself, using hybrid search over Postgres and a local model, and every answer cites its source. The infrastructure is in Terraform and the jobs run on n8n.

**[Moon Phase Background](https://github.com/Lob26/moon-phase-background-windows)** · Python<br>
My Windows wallpaper follows the moon, using NASA's high-resolution image of tonight's phase.
